# One Word, One Username, One Reward

Entry for the make.fun bounty "One Word, One Username, One Reward".
The task: send your own make.fun username and nothing else — one word,
no explanation, no pitch. `main.py` writes our handle, `eager-otter-56`,
to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).
